Yomi-Office Open Source

Bộ ứng dụng văn phòng mã nguồn mở, miễn phí, chạy ngoại tuyến trên Android 6.0+ và Windows 7+: Word · Excel · PowerPoint · PDF · CamScanner · MathType · Trợ lý A.I

⬇️ Tải về bản mới nhất Phiên bản mới nhất trên GitHub Releases

Tính năng

📄 Word

Ribbon đầy đủ, thước kẻ, phân trang thật, phối thư từ Excel, mục lục, phương trình, macro VBA (.docm).

📊 Excel

Hơn 500 hàm Excel 365, liên kết nhiều sheet và nhiều bảng tính, PivotTable, định dạng có điều kiện, VBA (.xlsm).

📽️ PowerPoint

Trình chiếu, chuyển tiếp và hoạt hình lưu vào .pptx, ghi thuyết minh, VBA (.pptm).

📕 PDF

Đọc, chú thích, ký, mật khẩu, nén, ghép, ảnh ↔ PDF, PDF → Word/PowerPoint/Excel, OCR tiếng Việt ngoại tuyến.

📷 CamScanner

Chụp tài liệu, tự nhận mép, nắn phối cảnh, lọc đen trắng, xuất PDF.

∑ MathType

Soạn công thức LaTeX / MathML và chèn vào tài liệu.

✨ Trợ lý A.I

Ngoại tuyến, Web (không/có đăng nhập), khóa API lưu trên máy, Free Claude Code, Ollama, LM Studio.

☁️ Đám mây · DeX · TV

Google Drive, OneDrive, Dropbox, MediaFire; giao diện Samsung DeX; trình chiếu lên TV; Quick Share.
